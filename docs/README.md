## 为什么值得读

这份报告**刻意保留了全部被推翻的结论**。它记录的不是一条笔直的成功路径，而是：

- **11 条被严格证伪的技术路线** —— 每条都有可复现的数据链
- **5 条可迁移的科学发现** —— 其中最核心的是「**16 MiB 字节大小律**」：ANE 外部权重取数速率只由权重张量字节数决定，与 K/N 无关（23/23 命中，惩罚 2.57×）
- **30 条方法论铁律** —— 每条都对应一次被测量假象欺骗的真实事故

如果你想了解：

- **为什么这个项目不做 ANE 卸载** → 第 14 章（含推翻过程）与第 22 章（最终修正后的图景）
- **为什么它不信任无风扇 Mac 上的短时基准** → 第 2 章与第 21 章
- **投机解码的边界在哪** → 第 16 章与第 27.1 节
- **踩过哪些工程坑** → 第 27.2、27.3 节

## 关键结论速览

> **Proteus 用 11 条被严格证伪的技术路线，换来了一张完整的 M5 硬件能力边界图，并最终在唯一幸存的杠杆上取得了产品级成果：Speculative Decoding 在真实网关上线，默认温度路径端到端提速 1.284×。**

| 维度 | 状态 |
|---|---|
| 小内存 | ✅ 4.21 GB 跑 8B（MLX 生态功劳） |
| 大模型 | ✅ 8B 数值等价 |
| 高速度 | 🟨 1.284×（唯一有效杠杆已上线） |
| ANE 路线 | 🟥 关闭（decode 零和，非硬件限制而是编译器 + 带宽 + 算力） |
